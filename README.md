# 📚 DSA Visualizer

An interactive **Data Structures and Algorithms visualizer** built with Python and Streamlit.

The project transforms theoretical DSA concepts into interactive visual experiences, making it easier to understand how algorithms work step by step.

---

## 🚀 Overview

Data Structures and Algorithms are often difficult to understand through theory and code alone.

This project provides an interactive environment where users can explore algorithm behavior visually and understand how input changes affect the execution of an algorithm.

---

## ✨ Features

### 🔎 Searching Algorithms

* Linear Search
* Binary Search

### 🔄 Sorting Algorithms

* Bubble Sort
* Selection Sort
* Insertion Sort
* Merge Sort
* Quick Sort

### 🌳 Data Structures

The visualizer is designed to demonstrate fundamental data structures and their operations.

### 📊 Interactive Visualization

* Enter custom input
* Visualize algorithm execution
* Observe intermediate steps
* Understand algorithm behavior
* Compare algorithm characteristics

## 🧠 Algorithms & Complexity

| Algorithm      |       Best |    Average |      Worst |
| -------------- | ---------: | ---------: | ---------: |
| Linear Search  |       O(1) |       O(n) |       O(n) |
| Binary Search  |       O(1) |   O(log n) |   O(log n) |
| Bubble Sort    |       O(n) |      O(n²) |      O(n²) |
| Selection Sort |      O(n²) |      O(n²) |      O(n²) |
| Insertion Sort |       O(n) |      O(n²) |      O(n²) |
| Merge Sort     | O(n log n) | O(n log n) | O(n log n) |
| Quick Sort     | O(n log n) | O(n log n) |      O(n²) |

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/MrunalAiNexus/dsa-visualizer.git
cd dsa-visualizer
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
